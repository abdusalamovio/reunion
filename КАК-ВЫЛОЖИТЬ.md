# Как выложить игру

Шпаргалка. Подробности — в [README](README.md#как-выложить-в-интернет).

## Команда

```bash
cd ~/projects/personal/reunion
./publish-web.sh
```

## Порядок

1. **Construct:** *Menu → Project → Export project → **Web (HTML5)***,
   минификация **none** или **simple** (advanced ломает скрипты).
2. Архив скачался в Загрузки — ничего не перекладывать.
3. Выполнить команду выше. Скрипт сам найдёт свежую сборку, выложит её и
   напечатает ссылку.

Игра: <https://abdusalamovio.github.io/reunion/> (появляется через минуту-две
после публикации).

## Если что-то не так

| Что видно | Что делать |
|---|---|
| Экспорт в Construct не запускается | *Project statistics* → «total lines of JavaScript code» больше 500, надо сократить код |
| `В ~/Downloads нет ни zip-архива, ни папки со сборкой` | Экспорт не скачался или лежит не в Загрузках — передать путь: `./publish-web.sh путь/к/архиву.zip` |
| `Сборка не отличается от опубликованной` | Этот экспорт уже выложен, делать нечего |
| На сайте старая версия | Обновить страницу с зажатым **Shift** — сборку кеширует service worker |
