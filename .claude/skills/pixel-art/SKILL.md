# Спрайты

PIL в окружении нет и ставить его не нужно. `scripts/canvas.py` пишет PNG сам,
на zlib из стандартной библиотеки.

```python
import sys
sys.path.insert(0, ".claude/skills/pixel-art/scripts")
from canvas import Canvas, PALETTE, zoom

c = Canvas(44, 60)
c.ellipse(22, 22, 12.5, 11, PALETTE["brass"], PALETTE["outline"])
c.save("images/olly-default-000.png")
```

Примитивы: `put`, `rect`, `ellipse`, `ring`, `thick_line`, `fill`,
`flipped_x`. У `rect` и `ellipse` второй цвет — контур.

## Обязательно: посмотри, что нарисовал

Спрайт 44x60 глазами не разобрать. Увеличивай и открывай:

```python
zoom("images/olly-default-000.png", "<scratchpad>/olly_x6.png", 6)
```

Результат — в scratchpad сессии, не в репозиторий. Первый подход почти всегда
кривой: у Олли руки утонули в корпусе и слиплись ступни, ключ вышел киркой.
Смотреть обязательно.

## Палитра

Менять в `PALETTE`, а не по месту, иначе кадры разойдутся по тону.

Логика направления: фон и передний план — холодное железо, единственные тёплые
пятна — латунь и янтарь. Олли, его ключ, глаза жуков, окантовка панциря и рамка
интерфейса тёплые; всё остальное холодное. Поэтому игрок всегда видит, где он и
где враг, даже в темноте.

## Правила, добытые на ошибках

**Растянутые спрайты размазывают вертикальные детали.** Плиты пола растянуты по
X в десятки раз. В их текстуре только горизонтальные полосы. Болты и кронштейны
— отдельные нерастягиваемые объекты.

**Передний план отделяется силуэтом.** Яркая холодная кромка сверху, под ней
почти чёрная масса. Когда пол был по тону как стена, сцена превращалась в кашу.

**Зеркальный кадр вместо поворота.** `angleDegrees = 180` переворачивает и по
вертикали. Для взгляда влево рисуй второй кадр через `flipped_x()` и зеркаль
`collisionPoly` по X.

**Размер кадра и экземпляра — разные вещи.** Кадр можно рисовать крупнее ради
деталей, а экземпляр ужимать через `setSize`. Так сделан ключ: кадр 72, в игре
50.
