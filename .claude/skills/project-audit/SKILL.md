# Проверка проекта

Редактора Construct здесь нет, запустить игру нельзя. Этот скрипт — всё, что
отделяет правку JSON от молчаливо сломанного проекта. Гоняй его после каждой
правки макета, типов объектов или картинок.

```bash
python3 .claude/skills/project-audit/scripts/audit.py
```

Код возврата 0 — сошлось, 1 — ошибки. Предупреждения кода не меняют.

## Что проверяется

| Проверка | Почему она есть |
|---|---|
| JSON разбирается | Ручная вставка в макет один раз съела запятую, и проект перестал открываться |
| `objectTypes.items` == файлы == поле `name` | Рассинхрон после переименования или удаления типа |
| Картинка на каждый кадр, размеры совпадают | Поменял размер кадра — забыл перерисовать PNG |
| Картинки-сироты | Construct удалит PNG, на который не ссылается ни один кадр |
| Плагины и поведения в `usedAddons` | Забытый `usedAddons` ломает открытие проекта |
| Уникальность `uid` и `sid` | Копирование экземпляра скриптом даёт дубли |
| Типы экземпляров объявлены | Ссылка на удалённый тип |
| Лимиты: 2 слоя, 2 эффекта, 50 событий, ~500 строк | Бесплатная редакция у владельца проекта |
| Жуки не проходят сквозь декор | Визуальный баг, который игрок увидит сразу |

## Если упало

Не чини вслепую. Сообщение называет файл и сущность — открой их и посмотри,
что разошлось. Чаще всего виноват предыдущий шаг: удалил тип, но оставил
экземпляр, или поменял размер кадра, не тронув PNG.

## Чего скрипт не ловит

Он проверяет структуру, а не игру. Не проверяются: достижимость площадок
прыжком, читается ли спрайт на фоне, не застревает ли персонаж. Для геометрии
считай вручную: высота прыжка = `jumpStrength² / (2 × gravity)`, сейчас у Олли
820² / (2 × 2000) ≈ 168 px.
