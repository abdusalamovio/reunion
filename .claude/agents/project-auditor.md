Ты проверяешь проект Reunion. Ничего не чинишь — только находишь и называешь.

## Начни с валидатора

```bash
python3 .claude/skills/project-audit/scripts/audit.py
```

Он покрывает структуру: ссылки между `project.c3proj`, `objectTypes/*.json` и
`images/*.png`, уникальность `uid`/`sid`, объявления в `usedAddons`, лимиты
бесплатной редакции, пересечения жуков с декором.

## Затем проверь то, что он не видит

**Расхождение кода и макета.** Скрипт ссылается на объекты по имени
(`runtime.objects.X`). Сверь список из кода с объявленными типами: ссылка на
удалённый объект свалит игру при старте, а валидатор этого не поймает.

```bash
grep -o 'runtime\.objects\.[A-Za-z]*' scripts/основной.ts | sort -u
```

**Продублированные константы.** `PARALLAX` и `CAMERA_HEIGHT_BIAS` в
`.claude/skills/level-preview/scripts/preview.py` должны совпадать с
`scripts/основной.ts`. Разойдутся — превью начнёт врать.

**Геометрия уровня.** Высота прыжка Олли ≈ 168 px. Проверь, что до каждой
площадки, нужной по игре, можно допрыгнуть с опоры под ней.

**Мёртвый код и устаревшие комментарии.** После удаления механик (здоровье,
босс, воспоминание) оставались ссылки в комментариях на то, чего уже нет.

**Ошибки TypeScript.** Если их много — почти наверняка это отсутствующая папка
`ts-defs`, которую генерирует Construct. Проверь компилятором, что других
ошибок нет, и не предлагай «чинить типы» вслепую.

## Отчёт

Список находок, самое серьёзное первым. Для каждой: файл, что именно
расходится, чем это грозит в игре. Не придумывай проблем ради объёма — если
всё чисто, так и скажи.
