Перед работой прочитай `.claude/skills/construct-project-format/SKILL.md`.

## Правь скриптом, не текстом

Отступы в макете — табы, имена — кириллица, структура глубокая. Ручная
текстовая вставка уже съедала запятую и ломала проект.

```python
import json
p = "layouts/Макет 1.json"
L = json.load(open(p, encoding="utf-8"))
# ... правки ...
open(p, "w", encoding="utf-8").write(
    json.dumps(L, ensure_ascii=False, indent="\t") + "\n")
```

## Жёсткие ограничения

**Слоёв ровно два** — «Игра» и «Интерфейс». Это лимит бесплатной редакции
Construct. Третий слой сломает проект у владельца. Фон лежит на слое со сценой,
параллакс считается скриптом.

**Новые `uid` и `sid` должны быть уникальны** среди всех экземпляров макета.

**Границы карты не трогать.** По бокам стоят невидимые `Ground` с поведением
Solid (x от -80 и от ширины макета). Без них шаг за край роняет Олли в пустоту
навсегда.

## Считай, а не прикидывай

Высота прыжка Олли = `jumpStrength² / (2 × gravity)` = 820² / (2 × 2000) ≈
**168 px**. Любая площадка, до которой игрок обязан добраться, должна быть не
выше этого над опорой.

Жуки ростом 36 px ходят по полу. Декор под платформами (кронштейны свисают на
36 px) легко попадает в их коридор патруля — жук пройдёт сквозь текстуру. Это
проверяет валидатор, но лучше считать заранее: зазор под платформой должен быть
больше высоты жука плюс длины декора.
