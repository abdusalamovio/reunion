# Reunion

2D-платформер в стимпанке на Construct 3. Заводной робот Олли ищет Оливера —
мальчика, который его когда-то собрал. По задумке Олли проходит четыре
локации-воспоминания по три уровня, в конце каждой побеждает босса и
возвращает воспоминание, а в финале его находит сын уже взрослого Оливера.

**▶ Играть в браузере: <https://abdusalamovio.github.io/reunion/>**

Ничего скачивать и устанавливать не нужно.

## Управление

| Действие | Клавиша |
|---|---|
| Идти | `A` / `D` |
| Прыжок | `Пробел` |
| По лестнице вверх / вниз | `W` / `S` |
| Удар ключом | Левая кнопка мыши |

## 🔄 Если открылась старая версия

Браузер хранит прошлую версию игры и первым открытием показывает её, а новую
тем временем качает в фоне. Если видите старую версию:

1. **Обновите страницу** — обычно этого хватает: **Cmd+R** (macOS) или **F5**
   (Windows, Linux).
2. Не помогло — обновите без кеша: **Cmd+Shift+R** (macOS) или
   **Ctrl+Shift+R** (Windows, Linux).
3. Всё ещё старая — очистите данные сайта: DevTools (F12) → **Application** →
   **Storage** → **Clear site data**, затем обновите страницу.

## Стадия: ранний прототип

Собраны первая локация и этажи второй. Это не игра целиком и не демо для
игроков — это проверка того, что управление, бой и подача читаются.

**Что работает**

- Первая локация — детская: три уровня, «Детская 1», «Детская 2»,
  «Детская 3», у каждого свой фон, платформы, пружины и враги. Третий уровень
  короче, в его конце босс
- Вторая локация — старая мастерская: три этажа, «Старая мастерская 1–3», с
  платформами, пружинами и лестницами. Врагов и босса на них пока нет
- Выход с уровня — стимпанк-портал: разгорается, когда Олли рядом, вошёл —
  следующий уровень. На уровне с боссом загорится только после победы. На последнем этаже портала нет
- Олли: бег, прыжок, удар гаечным ключом — с анимациями по раскадровке
  дизайнера
- Камера: плавно догоняет игрока, смотрит вперёд по бегу, не выходит за карту
- Враги — заводные мышь, птица и гусеница: патрулируют, замечают Олли,
  бросаются в погоню и атакуют. С разбитых падают гайки и болты
- Босс детской — заводной медведь: бьёт когтями, прыгает с ударной
  волной, бросает кубики. После победы оставляет ядро

**Чего ещё нет**

- Здоровья игрока и урона в единицах: удар врага только отбрасывает Олли,
  враг разбивается с двух ударов, медведь — с восьми
- Системы улучшений: детали и ядро подбираются, но ни на что не влияют;
  меню самомодификации нет
- Комбо из 2–3 ударов, рывка с уклонением, контрольных точек — Олли
  возрождается в начале уровня
- Управления с геймпада
- Врагов и босса старой мастерской
- Остальных локаций — двора и новой мастерской: ждут дизайна
- Экрана победы, звука, меню, сохранений

Олли, враги, босс и портал нарисованы дизайнером, фоны, платформы и пружина
детской — из уровней разработчика. Пружина мастерской пока собственная.

## Как открыть

Нужен [Construct 3](https://www.construct.net/). Открыть папку проекта как
Construct project folder (не `.c3p`-архив). Запуск — Preview в редакторе.

Git для этого не обязателен: файлы можно скачать архивом — на странице
репозитория **Code → Download ZIP**, — распаковать и открыть получившуюся
папку как Construct project folder.

Проект рассчитан на **бесплатную редакцию** и держится в её лимитах: 2 слоя на
макет, 0 событий, 0 эффектов. Вся логика написана на TypeScript, листов событий
в проекте нет принципиально. За лимитами стоит следить: при выходе за них
редактор не даёт сделать экспорт.

## Что где лежит

```
project.c3proj          индекс проекта Construct
scripts/main.ts         вся игровая логика
layouts/*.json          уровни «Детская 1–3» и «Старая мастерская 1–3», у
                        каждого слои «Фон» и «Игра»
objectTypes/*.json      описания типов объектов
images/*.png            спрайты
icons/                  иконки приложения
ts-defs/                упрощённые типы Construct для проверки TypeScript
```

Что на уровне:

- `Shelf` — платформа для прыжка, один объект: и картинка, и опора, на неё
  можно запрыгнуть снизу. Размер — анимацией `ShelfM` или `ShelfL`
- `Spring` — пружина: встал на неё — подбрасывает
- `Portal` — выход в следующий уровень
- `Ground` — невидимая опора пола, картинка пола над ней — `Deco`
- `Wall` — стенки за краями уровня, чтобы не выйти за край
- `NurseryPlatform…`, `NurseryPedestal`, `NurseryColumn` — опоры детской,
  `WorkshopPlatform…`, `WorkshopPedestal`, `WorkshopBracket`, `WorkshopColumn` —
  опоры мастерской. На платформы можно запрыгнуть снизу
- `Ladder` — лестница, по ней лезут на `W` / `S`
- `NurseryFloor`, `WorkshopFloor` — картинка пола
- `NurseryBackdrop1…3`, `WorkshopBackdrop1…3` — фоны, по одному на уровень
- `Wrench`, `Part`, `Core`, `Cube` на уровни не ставятся: их создаёт код
  (зона удара ключом, выпавшие детали, ядро и кубики босса)
