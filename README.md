# Reunion

2D-платформер в стимпанке на Construct 3. Заводной робот Олли ищет Оливера —
мальчика, который его когда-то собрал. По задумке Олли проходит четыре
уровня-воспоминания, на каждом побеждает босса и возвращает воспоминание, а в
финале его находит сын уже взрослого Оливера.

Учебный проект, некоммерческий.

## Стадия: ранний прототип

Готов вертикальный срез одного уровня. Это не игра целиком и не демо для
игроков — это проверка того, что управление, бой и подача читаются.

**Что работает**

- Управление платформера: ходьба, прыжок, удар гаечным ключом
- Камера: плавно догоняет игрока, смотрит вперёд по бегу, не выходит за карту
- Бой: механические жуки с здоровьем, отбросом и патрулём; с них падают детали
- Уровень 2560×960: пол, площадки, невидимые границы карты
- Оформление: фон с параллаксом, туман, силуэтный передний план, HUD

**Чего ещё нет**

- Боссов. Концепты четырёх есть, в прототипе ни одного
- Системы улучшений: детали считаются, но ни на что не влияют
- Здоровья игрока: касание жука только отбрасывает
- Звука, меню, сохранений, остальных трёх уровней
- Анимаций: все спрайты однокадровые, кроме зеркальных кадров ключа

Графика целиком — временные заглушки, нарисованные кодом. Они задают палитру и
композицию, но это не финальный арт.

## Как открыть

Нужен [Construct 3](https://www.construct.net/). Открыть папку проекта как
Construct project folder (не `.c3p`-архив). Запуск — Preview в редакторе.

Проект рассчитан на **бесплатную редакцию** и держится в её лимитах: 2 слоя на
макет, 0 событий, 0 эффектов. Вся логика написана на TypeScript, листов событий
в проекте нет принципиально.

## Управление

| Действие | Клавиша |
|---|---|
| Идти | `A` / `D` |
| Прыжок | `Пробел` |
| Удар ключом | Левая кнопка мыши |

Цель уровня — разбить всех жуков.

## Что где лежит

```
project.c3proj          индекс проекта Construct
scripts/основной.ts     вся игровая логика
layouts/Макет 1.json    уровень: геометрия, враги, фон, декор
objectTypes/*.json      описания типов объектов
images/*.png            спрайты
icons/                  иконки приложения
```

Файлы `*.uistate.json` — состояние редактора Construct, в репозиторий не
попадают и на игру не влияют.
