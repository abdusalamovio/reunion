# Reunion

2D-платформер в стимпанке на Construct 3. Заводной робот Олли ищет Оливера —
мальчика, который его когда-то собрал. По задумке Олли проходит четыре
уровня-воспоминания, на каждом побеждает босса и возвращает воспоминание, а в
финале его находит сын уже взрослого Оливера.

**▶ Играть в браузере: <https://abdusalamovio.github.io/reunion/>**

Ничего скачивать и устанавливать не нужно. Управление — [ниже](#управление).

## ⚠️ Игра не обновилась? Сбросьте кеш

Браузер хранит прошлую версию игры и первым открытием показывает её, а новую
тем временем качает в фоне. Если видите старую версию:

1. **Закройте все вкладки с игрой и откройте её заново.**
2. Не помогло — обновите страницу без кеша: **Cmd+Shift+R** (macOS) или
   **Ctrl+Shift+R** (Windows, Linux).
3. Всё ещё старая — очистите данные сайта: DevTools (F12) → **Application** →
   **Storage** → **Clear site data**, затем обновите страницу.

## Стадия: ранний прототип

Готов вертикальный срез первого уровня. Это не игра целиком и не демо для
игроков — это проверка того, что управление, бой и подача читаются.

**Что работает**

- Уровень — ночная мастерская-детская: ступенчатый пол, мебель, латунные полки,
  пружины-батуты. Фон в два плана с параллаксом
- Олли: бег, прыжок, удар гаечным ключом — с анимациями по раскадровке
  дизайнера
- Камера: плавно догоняет игрока, смотрит вперёд по бегу, не выходит за карту
- Враги — заводные мышь, птица и гусеница: патрулируют, замечают Олли,
  бросаются в погоню и атакуют. С разбитых падают гайки и болты
- Босс в конце уровня — заводной медведь: бьёт когтями, прыгает с ударной
  волной, бросает кубики. После победы оставляет ядро

**Чего ещё нет**

- Здоровья игрока: удар врага только отбрасывает Олли
- Системы улучшений: детали и ядро подбираются, но ни на что не влияют
- Экрана победы, звука, меню, сохранений, остальных трёх уровней

Олли, враги и босс нарисованы дизайнером. Части уровня — пол, мебель, полки,
декор — пока собственные, в палитре концепта дизайнера; их заменят финальные.

## Как открыть

Нужен [Construct 3](https://www.construct.net/). Открыть папку проекта как
Construct project folder (не `.c3p`-архив). Запуск — Preview в редакторе.

Git для этого не обязателен: файлы можно скачать архивом — на странице
репозитория **Code → Download ZIP**, — распаковать и открыть получившуюся
папку как Construct project folder.

Проект рассчитан на **бесплатную редакцию** и держится в её лимитах: 2 слоя на
макет, 0 событий, 0 эффектов. Вся логика написана на TypeScript, листов событий
в проекте нет принципиально. За лимитами стоит следить: при выходе за них
редактор не даёт сделать экспорт.

## Что где лежит

```
project.c3proj          индекс проекта Construct
scripts/main.ts         вся игровая логика
layouts/Макет 1.json    уровень: слои «Фон» и «Игра», опоры, враги, декор
objectTypes/*.json      описания типов объектов
images/*.png            спрайты
icons/                  иконки приложения
ts-defs/                упрощённые типы Construct для проверки TypeScript
```

На макете видимое и твёрдое разделено: пол, мебель и полки нарисованы
частями декора (`Deco`), а стоит Олли на невидимых коллайдерах под ними —
`Ground` (твёрдый) и `Shelf` (можно запрыгнуть снизу). Двигая опору в
редакторе, двигайте и картинку, и коллайдер.
